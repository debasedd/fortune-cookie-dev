# Fortune Cookie Wisdom for Developers

[![Fortune Cookie Wisdom for Developers](https://make.fun/badge/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44.svg)](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)

A tiny program for [Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — one original line of fortune-cookie wisdom for a software developer:

> Your legacy code is not a mess; it is a diary of every deadline you survived.

Run it with:

```sh
python3 main.py
```
